\subsection{Prototype / MVP Demonstration}

\subsubsection{Product Concept}
Uvie brings together two fields. \emph{Chemical engineering} supplies the patch: safe
photochromic pigment mixed into a medical-grade gel and coated onto a hypoallergenic hydrocolloid
or silicone base to form a UV-sensitive sticker. \emph{Computer science} supplies the app, which
uses the phone camera to read the color of the patch.

The user sticks the patch on the skin and spreads sunscreen over both the skin and the patch.
As the sunscreen wears off through sweat, friction, or time, UV reaches the patch and it changes
color. The user scans the patch, and the app tells them to reapply (Figure~\ref{fig:concept-image}).
In the full vision, the app would also send a push notification; the MVP described below answers
only when the user scans.

\subsubsection{What the MVP Is}
Uvie's minimum viable product has two parts that work together. The first is a
UV-sensitive photochromic patch that stays light while sunscreen blocks UV and
turns dark once UV reaches it. The second is a web app that reads the patch color
through the phone camera and tells the user whether to reapply sunscreen. The MVP
is deliberately small: it tests the one idea the whole venture depends on, namely
that a person can look at a patch, scan it, and get a clear ``reapply'' signal.

The web app is live at \href{https://sun-check.onrender.com}{sun-check.onrender.com}
and its source code is in the project repository. It is built with React, Vite,
TypeScript, and Tailwind CSS, and it is hosted as a static site, so it needs no
server and no installation. Camera access requires HTTPS, which the hosting
provider supplies by default.

\paragraph{How the classification works.}
The app takes the central 40\% of the captured image, which is where the on-screen
guide asks the user to place the patch, and averages its pixels. It converts the
average color to a luminance value between 0 (black) and 255 (white) using the
standard weights for red, green, and blue (0.2126, 0.7152, and 0.0722). A luminance
below 120 is treated as a dark patch, so the app reports \emph{Reapply}; anything
else is reported as \emph{Protected}. The confidence value starts at 60\% right at
the threshold and rises linearly to a cap of 98\% once the luminance is 60 or more
units away from it (Figure~\ref{fig:confidence}). Because of this, a patch that sits
close to the threshold produces a low-confidence result rather than a false sense
of certainty.

\paragraph{Privacy by design.} The analysis runs entirely in the user's browser.
Captured frames are not uploaded, and the scan history is stored only in the
browser's local storage. This keeps the MVP simple and avoids collecting images of
users' skin, which is a sensitive issue for a product worn on the body.

\subsubsection{Physical Prototype: The UV-Sensitive Patch}
The physical prototype is a small round sticker made in three steps, described in
the product specification:
\begin{enumerate}[itemsep=0pt]
  \item \textbf{Mix.} Blend photochromic pigment into a medical solvent to form a
    thick ink.
  \item \textbf{Coat.} Spread a very thin, even layer of ink on the non-sticky face
    of a hydrocolloid patch or transparent medical tape.
  \item \textbf{Dry and cut.} Dry the coated sheet away from sunlight, since
    daylight would activate the pigment early, then punch out small circles.
\end{enumerate}
The simple bench test is to stick a patch on the back of the hand and apply
sunscreen over it. In sunlight or under a UV lamp, the patch should stay light
while the sunscreen holds. Wiping the sunscreen off with a wet cloth, to imitate
sweat, should make the patch turn dark immediately.

\subsubsection{Why This Mechanism Is Credible}
Uvie did not invent the principle. A series of field studies in Australia tested
commercial UV-detection stickers that work in the same way. In one study with
adolescent rugby players, handing out stickers was linked to more than three times
as much sunscreen being used on the second event day compared with the first
\cite{horsham2020}. An earlier study by the same group found that stickers helped
adults reapply sunscreen at an outdoor event \cite{hacker2019}. These results come
from sports events in Australia and from a different sticker product, so they
support the idea but are not proof that Uvie's patch will work in Vietnam.

\subsubsection{Development Process}
\begin{itemize}[itemsep=0pt]
  \item \textbf{Specification first.} The team wrote a product specification and a
    short brand guideline before coding. The guideline sets a calm, direct tone,
    a blue brand color kept separate from the green, amber, and red status colors,
    and a rule that every status color must come with an icon and a text label, so
    that the result never depends on color alone.
  \item \textbf{UI-first build.} The interface was built first with mock analysis so
    that all screens could be navigated and demonstrated before any image processing
    existed. The current build already replaces the mock with the simple brightness
    rule described above.
  \item \textbf{Mobile first.} Layouts are designed for phones, with large tap
    targets, because scanning happens outdoors with one hand.
  \item \textbf{Static deployment.} The app is published as a static site and is
    redeployed automatically each time new code is pushed to the main branch.
\end{itemize}

\subsubsection{Known Limitations and Next Steps}
We want to be clear about the weaknesses of the current prototype.
\begin{itemize}[itemsep=0pt]
  \item \textbf{The classifier is a heuristic.} It looks only at average brightness,
    so strong glare, shadows, or a dim room can change the reading. A possible
    improvement, still to be tested, is to print a reference color beside the
    patch so that lighting affects both in the same way.
  \item \textbf{Photochromic indicators have limits.} A laboratory study of ten
    commercial photochromic devices found that they changed color within about a
    minute even under SPF 50+ sunscreen at a UV index of 10, and that their color
    saturated at moderate UV levels. The authors concluded that such devices can
    raise awareness but are of limited use for measuring UV dose \cite{aguilera2024}.
    Uvie should therefore be described as a reminder tool and not as a measurement
    device, and our own patches need to be tested under Vietnamese UV conditions,
    which are often above index 9 (Figure~\ref{fig:uv-vietnam}).
  \item \textbf{No reminder scheduling yet.} The app answers only when a user scans.
    Timed reminders and notifications are on the roadmap.
\end{itemize}
The roadmap has four phases: a UI with mock analysis (done), real color sampling and
classification, reminder scheduling, and finally accounts and analytics.
